Administration / Configuration

System settings

Super Admin workspace. Manage role assignments in the Users sheet.

User access management

Open the linked Google Sheet → Users tab. Add each user's Google account email, name, role (Super Admin / Supervisor / Employee), department and Active = TRUE. Access is enforced by the server-side Code.gs role checks.

Important: the current backend uses the signed-in Google account email for identity. Deploy with an account/domain configuration that exposes Session.getActiveUser().getEmail(). Do not deploy as anonymous/public for financial records.

Google Sheets backend

The setupApp() function creates the required registers. Run it once from Apps Script editor after binding the project to your target Google Sheet.
